# Nodirbek Fatkhullaev — independent portfolio

Static HTML/CSS/JavaScript site. Open `index.html` directly or serve this folder with any static HTTP server. No build, npm installation, environment variables or backend required. Google Fonts are optional; system font fallbacks work offline.

## Separate deployment

Source repository: https://github.com/nathankuroshiro/CV2026. Connect this repository to a separate Vercel project. Framework: Other; no build command; output directory: `.`. Push updates to `main` to trigger automatic deployments. Never connect this project to the old `nathankuroshiro/cvbek` repository or its Vercel project.

## Content and provenance

Name, Tashkent location, Webster University student status, languages and email are from the original portfolio index.html, read through GitHub. Technical skills and SANCTUM commercial / Lux Travel concept classification were supplied by the user. Original case study images are independent copies of public files from nathankuroshiro/cvbek. No employment dates, employers, certifications, performance metrics or professional achievements were invented. The original cvbek repository remains unchanged.

Print CV opens the browser print dialog; choose Save as PDF. Copy email uses the clipboard where available and displays the address if clipboard access is unavailable.
